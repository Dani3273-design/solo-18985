# 切水果游戏

使用 Python 和 Pygame 开发的经典切水果游戏。

## 功能特性

- 三种水果：苹果、香蕉、菠萝
- 炸弹机制，切到炸弹游戏结束
- 真实的物理抛物线和重力效果
- 水果被切后一分为二的视觉效果
- 炸弹爆炸粒子特效
- 鼠标滑动轨迹显示
- 30秒倒计时
- 游戏结算统计

## 安装说明

### 环境要求

- Python 3.9 或更高版本
- pip 包管理器

### 安装依赖

```bash
pip install pygame
```

### 运行游戏

```bash
cd main
python main.py
```

## 游戏说明

### 操作方法

1. 点击「开始游戏」按钮开始游戏
2. 按住鼠标左键并滑动来切水果
3. 尽量避开炸弹

### 计分规则

- 切到一个水果：1分
- 一次切到多个水果，有多少算多少，最多3分
- 切到炸弹：游戏结束

### 游戏机制

1. **物理系统**：水果从屏幕底部抛出，遵循真实的抛物线运动和重力加速度
2. **水果类型**：
   - 苹果：红色圆形水果
   - 香蕉：黄色椭圆形水果
   - 菠萝：橙黄色带绿叶的水果
3. **炸弹**：黑色圆形，带引信和火花，概率低于水果
4. **时间限制**：每局游戏30秒
5. **游戏结束条件**：
   - 时间耗尽
   - 切到炸弹

### 结算统计

游戏结束后会显示：
- 最终得分
- 切到水果的个数
- 没切到水果的个数
- 总用时

## 技术实现

### 多线程设计

游戏采用多线程设计来保证操作流畅性：
- 主线程：负责渲染和用户输入
- 物理线程：后台更新物体位置和状态，避免卡顿

### 碰撞检测

使用线段与圆形相交检测算法来检测鼠标滑动轨迹是否切到水果或炸弹。

### 视觉效果

- **滑动轨迹**：使用渐变色的线条显示鼠标滑动路径
- **切开效果**：水果被切成左右两半，各自按不同方向飞出
- **爆炸效果**：炸弹爆炸产生30个粒子，带有不同颜色和透明度衰减

## 常见问题

**Q: 中文显示乱码怎么办？**

A: 游戏会自动尝试使用系统中文字体（如 PingFang SC、Heiti SC、Microsoft YaHei、SimHei 等）。如果都不可用，会使用默认字体。

**Q: 游戏卡顿？**

A: 游戏已采用多线程设计，物理更新在后台线程执行。如果仍有卡顿，请确保：
- 使用较新版本的 pygame
- 关闭其他占用大量 CPU 的程序

**Q: 如何修改游戏参数？**

A: 可以在 `main.py` 中修改以下参数：
- `WIDTH` / `HEIGHT`: 窗口大小
- `GAME_DURATION`: 游戏时长（秒）
- `FPS`: 帧率

在 `engine.py` 中可以修改：
- `spawn_interval`: 水果生成间隔（毫秒）
- `bomb_probability`: 炸弹出现概率
- `gravity`: 重力加速度
